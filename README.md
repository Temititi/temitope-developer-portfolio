# Temitope Matuluko — Portfolio

Refactored from the original single-file React portfolio. The visual design, copy, projects, social links, animations, and CSS are preserved.

## Run

```bash
npm install
npm run dev
```

## Structure

- `src/main.jsx` — React entry point
- `src/App.jsx` — page assembly
- `src/components/` — individually editable sections
- `src/data/projects.js` — projects and their live links
- `src/data/socials.js` — GitHub and LinkedIn
- `src/style.css` — existing visual styles
- `public/portrait.jpeg` — your uploaded portrait
